## Descripción del Proyecto
Sistema automatizado para la gestión segura y eficiente de donaciones de recursos físicos, control de inventarios, trazabilidad de entregas y generación de reportes de impacto para organizaciones comunitarias[cite: 1, 2].

## Tecnologías y Características
* **Base de Datos:** MySQL / MariaDB
* **Estructura:** Tablas relacionales con herencia de usuarios, índices de optimización.
* **Lógica de Base de Datos:** Procedimientos almacenados con control de transacciones y niveles de aislamiento, Triggers y Vistas.
* **Frontend:** Módulo visual integrado.

## Estructura del Repositorio
* `scripts/`: Contiene los scripts SQL divididos en tablas, índices, constraints, procedimientos, triggers y vistas.
* `frontend/`: Código fuente de la interfaz de usuario.
